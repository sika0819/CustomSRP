# UI（UI Toolkit 表单框架 / 运行时表单 / HUD）

模块文档索引见 [00-overview.md](00-overview.md)。

## 职责与边界

- 只用 UI Toolkit：`UIDocument` + `UXML` + `USS` + `VisualElement`。
  **禁止** `UnityEngine.UI` / `Canvas` / `GraphicRaycaster` / `TextMeshProUGUI` / `OnGUI`。
- 表单基类 `Game.UI.GameFormLogic : UnityGameFramework.Runtime.UIFormLogic`。
- 深度走 `UIDocument.sortingOrder`（= `uiGroupDepth * 100 + depthInUIGroup`），**不改** `PanelSettings.sortingOrder`。

## 关键 API

### GameFormLogic

```csharp
protected VisualElement Root { get; }                  // UIDocument.rootVisualElement
protected virtual bool SlidesUpFromBottom { get; }     // 默认 false
protected virtual bool CloseOnBackdropClick { get; }   // 默认 = SlidesUpFromBottom
protected virtual bool CloseWhenAnyButtonClicked { get; }

protected void OnClick(string elementName, Action action);
protected void CloseSelf();          // 带动画
protected void CloseSelfImmediate();  // 无动画
```

- 背景关闭手势要求 **pointer-down 与 pointer-up 都落在背景/根节点**上（名字含 "view" 的区域）。
- `PointerDownEvent` / `PointerUpEvent` 不是 `ClickEvent`，单独存在 `_trackingCallbacks` 里。

## 运行时表单要点

### IslandMainForm

- 元素名契约：`weatherBackground` `musicBackground` `volumeBackground` `presetIcon` `profile`
  `timerBackground` `timeBackground2` `timeDial` `timeHand` `timeLabel` `musicPlaying`(barLeft/barCenter/barRight)
  `musicvolumeyuan` `effectvolumeyuan` `volumeTrack1` `volumeTrack2` `hudHeader` `hudIcons`
  `breathHint` `pauseHint` `root`。
- 预设虹膜状态机 `IrisPhase { None → Exiting → Holding → Entering }`：
  `OutlensSeconds=2`、`VignetteStartSeconds=0.5`、`VignetteKeepSeconds=1`、`InlensSeconds=2`、
  `BlackHoldSeconds=0.16`（低端 0.08）。
- 天气图标档位：`ResolveWeatherIcon(kind, level)`，`idx = level - 1`。
  云层数组为 `{ 小云, 中云, 中云 }`（资源目录无「大云」贴图），雨/雾/风为 `{ 小, 中, 大 }`。

### MusicForm

- 常量：`AlbumNameGap=40`（邻接专辑名字尾→字首固定间距）、`AlbumStripCopies=3`、
  `TrackMarqueeGap=160`、`TrackMarqueeSpeed=80`、`TrackMarqueePauseSeconds=3`、
  `ScrollbarIdleHideSeconds=3`、`ScrollbarFadeSeconds=0.35`、`ModeTipSeconds=1.4`、
  `PlayingFrameCount=59`、`PlayingFrameIntervalMs=33`、`DragActivationPixels=6`。
- 元素名：`huadong` → `albumContent`、`modeIcon`、`modeButton`、`musicList`、`hintwindows`、`title`；
  曲目行 `titleMask` / `titleMover` / `label0`+`label1`（跑马灯双副本）/ `downloadsuccess`。
- 专辑条：`MeasureTextSize` 按 48/72 实测字宽排布，无省略号；字尾→字首间距恒为 `AlbumNameGap`；
  选中项中心对齐视口；拖动中冻结排版，松手再重排。疏密只改 `AlbumNameGap`。
- 歌名：文案 ≤ 遮罩宽则静止并隐藏副本；超出则双副本左移（间距 160、80px/s），第二段左缘对齐遮罩左缘后复位并停 3s 再循环；红点贴在歌名 Rect 右缘（遮罩外，不挡跑马灯）。
- 歌单滚动：UITK `ListView` 默认禁触摸拖滚，自管 `scrollOffset.y`（对齐 PresetForm）；滚动条拇指手势不抢。
- 曲目状态：对齐 `InGameYinYueItem`——`Playing` / 真正 `Downloading`（或用户刚点的 pending）显示转圈；
  队列里单纯 `Pending` 仍显示未下载云标；`Succeeded` 为歌名旁红点（非右侧大图标）。
- 状态图标资源：`Resources/MusicForm/MusicNotDownload|MusicLoading|MusicError|MusicRed`。
- 下载门禁：无网络 → 「需要网络连接」；空间不足（`可用 < 需求 × 2`）→「存储空间不足」；
  **移动流量确认仍是 TODO，当前直接放行**。

### PresetForm

- 常量：`ItemWidth=264`、`ItemGap=36`、`ClickSlop=14`、`TrackWidth=240`、`ThumbWidth=63`、
  `SidePad=60`、`ToastSeconds=1.6`、`BusyToastText="天气正在改变,稍后再操作"`。
- 卡片状态 `BankUiState { AllReady, NotDownloaded, Downloading, Failed, Playing, RedDot }`。
- 元素名：`presetButton` `presetList` `scrollTrack` `scrollTrackActive`，
  卡片子节点 `presetitem` `cover` `vip` `statedownloading`(→`fill`) `statewaitdownload`
  `stateerror` `statedownloadsuccess` `stateready` `stateplaying`。
- 下载完成回调 `OnPresetBanksDone` 里再 `RequestTransition` 自动进预设。

### WeatherForm

- 档位轨道左边距 `LevelMarginLeft = { -403.5, -184.5, 37.5, 259.5 }`，
  档位名 `{ 关闭, 小, 中, 大 }`，命中区 `closeLevel / levelSmall / levelMedium / levelLarge`，
  天气页签 `fengButton / yuButton / wuButton`。

### VolumeForm

- 键名常量 `MusicVolumeKey = "Volume.Music"`、`EffectVolumeKey = "Volume.Effect"`（历史遗留，实际存 `BoluoGameSave`）。
- 旋钮尺寸 144，填充条最小宽 204。

## 已知坑与排查手法

| 现象 | 原因 | 处理 |
|---|---|---|
| 表单打不开 / group missing | `EnsureUiGroups` 依赖 `UIComponent.Start` 先跑（GameEntry 执行顺序 100） | 看 `[ProcedureIsland] OpenUIForm` |
| 点背景关不掉 | down/up 落点必须都在背景区域 | 检查 UXML 的 "view" 命名区域 |
| 音量拖动中途关面板没保存 | `SaveVolume` 只在 `PointerUp` / `PointerCaptureOut` 触发 | 关闭路径补一次保存 |
| 音量条在小面板上拖不动 | 行程 = `trackWidth - 204`，面板太窄时被 clamp 到 1px | 查 `track.layout.width` |
| 天气图标错档 | 数组顺序必须「强度从小到大」 | 已修正云层数组 |
| 音乐面板首开卡顿 | 首次打开同步 `Resources.Load<Sprite>` 59 帧动画 + 3 个模式图标 | 低端机可考虑改为图集 |
| 预设红点每次都出现 | 已听标记由 `DownloadedUnplayedManager` 管理，游客会话不落盘 | 见 [03-persistence.md](03-persistence.md) |
| 预设卡片没封面 | `PresetTemplate` 为空 → `MakeItem` 只造 `Label` | 检查 prefab 上的 `PresetTemplate` 引用 |
| 创维闺蜜机开预设面板掉帧 | 进度 tick 曾全量扫 bank + 写 `display`/`opacity` 脏整卡封面；播放条改 `height` 布局 | `ProgressEpoch`/`HasBusyWork` 早退；Downloading 只脏 `ArcProgressRing`；`PresetEqualizerBars` mesh；封面只用 `IslandPresetAsset.Cover` |
| 弹出框尺寸随文字变窄 | `UiTipToast` 用 `chars × fontSize × 0.62` 估算宽度，中文偏窄 | 特殊排版需手调 |
| HUD 图标位置不对 | `IslandMainHudLayout` 只按面板高度缩放，X 固定设计单位 | 超宽屏两侧贴边是预期 |
| 闲置后 HUD 不回来 | 依赖 `OnApplicationFocus` / 点击事件 | 检查事件是否被 `presetVeil` 吞掉 |
